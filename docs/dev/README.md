# Design plans

These are the design specs (`specs/`) and the step-by-step implementation
plans (`plans/`) that a handful of larger features were built from in August
2026 — live money, theme and handicap corrections, feedback, the shareable
scorecard, quick-pick score entry, the Setup approachability pass. Each plan
was written for an AI coding agent working in short, test-first steps, which
is why they read the way they do: numbered tasks, exact file paths, verify
steps, and a few instructions aimed at the tooling of the day rather than at a
person. They are kept as the record of *why* those features have the shape
they have; they are not kept up to date, and where a plan and the code
disagree, the code and `CHANGELOG.md` are right. Nothing here is needed to
build or contribute — see `CONTRIBUTING.md` for that.
